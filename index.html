How BFS Works
  1. 1 Start node is added to the queue
  2. 2 Dequeue a node, explore its 4 neighbors
  3. 3 Unvisited neighbors are enqueued
  4. 4 Track parent to reconstruct path
  5. 5 Repeat until End node is reached
