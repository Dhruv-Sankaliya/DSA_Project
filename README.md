# 🧩 Maze Solver — DSA Project

> **Graph + BFS Algorithm | C Language + WebAssembly | Interactive Web UI**

---

## 📌 Project Overview

This project demonstrates a **Graph-based Maze Solver** where:

- A **random maze** is generated using the Recursive Backtracker algorithm
- The maze is modeled as a **Graph** (each open cell = node, adjacent open cells = edges)
- **BFS (Breadth-First Search)** finds the shortest path — implemented in **C language**
- The C code is compiled to **WebAssembly** and runs directly in the browser
- The solution path is animated visually on the screen

## 🚀 How to Run

### Step 1 — Compile the C Code

```bash
chmod +x compile.sh
./compile.sh
```

This will:
1. Auto-install **Emscripten** (if not already installed)
2. Compile `solver.c` → `solver.wasm` + `solver.js`

> ⚠️ First-time setup may take a few minutes (downloading Emscripten). After that, compiling takes ~5 seconds.

### Step 2 — Serve the Project Locally

```bash
python3 -m http.server 8080
```

### Step 3 — Open in Browser

```
http://localhost:8080
```

> **Note:** You must use a local server (not `file://`). Browsers block WebAssembly from `file://` for security reasons.

## 🧠 How the BFS Algorithm Works (C Code)

### Graph Construction
```
Maze Grid (open cells = nodes, passages = edges):

  S . . # .
  # # . # .
  . . . . .
  . # # # .
  . . . . E

Each "." cell is a NODE in the graph.
Adjacent "." cells share an EDGE.
```

### BFS Traversal
```
1. Start node added to Queue
2. Dequeue → explore 4 neighbors (N, S, E, W)
3. Unvisited neighbors enqueued + parent tracked
4. Repeat until End node is reached
5. Trace parent[] array backwards → reconstruct shortest path
```

### Time & Space Complexity
| Property | Value |
|----------|-------|
| Algorithm | BFS (Breadth-First Search) |
| Data Structure | Graph (Adjacency List) |
| Time Complexity | O(V + E) |
| Space Complexity | O(V) |
| Guarantee | **Shortest Path** |

## 📚 DSA Concepts Used

- **Graph** — Maze represented as an undirected graph
- **Adjacency List** — Efficient neighbor storage per node
- **BFS Queue** — FIFO queue for level-by-level traversal
- **Parent Array** — Tracks path for reconstruction
- **Recursive Backtracker** — DFS-based maze generation
